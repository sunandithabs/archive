EXCALIBUR · Lifecycle Threat Model
for Adaptive CAN IDS
Adaptive, online-learning intrusion detection is showing up on the CAN bus, and it keeps learning after it ships. Nobody has asked what happens if an attacker reaches it during the moment it's still calibrating.

EXCALIBUR names that window as an attacker-reachable surface and tests it with a bounded-budget timing attack against a live IDS, run on real vehicle CAN traffic across multiple sessions and targets. What it finds, and what it doesn't, is on the project page.
