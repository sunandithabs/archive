Automotive Security

ECU trust chains, UDS SecurityAccess, and CAN bus intrusion detection. Three projects, one thread: what it takes to trust a message on a bus that was never built to question anything.

// latest project
BOLT — Boot & OTA Lockdown Toolkit
Signed OTA update and boot integrity framework for automotive ECUs. Real X.509 trust chain, A/B partitioning, and a four-attack suite (downgrade, signature strip, MITM, power loss) that all get blocked.

WARDEN — UDS SecurityAccess Attack & Detection
SocketCAN testbed built on ISO 14229. Brute-forces a weak seed-key ECU simulation while a sliding-window detector on the same bus flags the attack in progress.

CANARY — CAN Bus Intrusion Detection Framework
